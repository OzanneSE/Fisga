# Fisga · Cozinha

Ferramentas da cozinha do Fisga (peixe, brasa e vinho · Pinheiros, São Paulo).

- `index.html`: entrada
- `checklist.html`: checklist por praça e guia do cozinheiro
- `cardapio.html`: cardápio de abertura, em revisão
- `grimorio.html`: grimório de bases (43 fichas); `grimorio_bases.json` são os mesmos dados, para importar no editor

Páginas estáticas, abrem no celular. Marcações ficam salvas no aparelho de cada um.
